安装小贴士

macOS：已 Apple 公证，正常安装即可；如遇「无法验证开发者」，请在 系统设置 → 隐私与安全性 中点击「仍要打开」。
Windows：安装包暂未代码签名，SmartScreen 提示时选择 更多信息 → 仍要运行；浏览器警告时选择「保留」。
应用内置自动更新，安装后无需再回到本页。
